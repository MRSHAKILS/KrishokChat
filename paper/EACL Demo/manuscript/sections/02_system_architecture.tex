\subsection{Architectural Blueprint}
\input{figures/fig1_cost_gated_decision_flowchart.tex}

KrishokChat is a decoupled full-stack platform built on port-and-adapter separation \citep{flexrag2025}: a FastAPI async backend behind a Next.js~14 frontend tuned for mobile web and PWA use. The separation keeps advisory logic provider-agnostic, so the same pipeline runs offline with a stub LLM or online with a hosted model without code changes.

\input{tables/tab1_system_capabilities.tex}

Figure~\ref{fig:system_architecture} and Table~\ref{tab:system_capabilities} summarize the end-to-end decision pipeline and five-tier resolution ladder. A query moves through five coordinated stages, each with a visible artifact and a measured cost:

\begin{enumerate}
    \item \textbf{Safety gate.} Six-way classification (\texttt{safe\_agri}, \texttt{banned\_chemical}, \texttt{self\_harm}, \texttt{off\_topic}, \texttt{prompt\_injection}, \texttt{low\_confidence}) via \texttt{safety\_policy.precheck} and an LLM guard. Unsafe queries end before retrieval with a calm redirect and a one-touch dial to the Krishi Call Center 16123. Measured p50~0.32\,ms on 400 Bengali queries.
    \item \textbf{Multimodal perception router.} When a photo is present, classification-only ONNX models identify crop and then disease to narrow the retrieval space. A 10-class YOLO26s edge classifier ($20.82$\,MB ONNX/TFLite, $99.55\%$ test top-1, $98.39\%$ real field accuracy across $n$=436) isolates crops and routes to per-crop disease models at 224--320\,px (including 8-class Chilli, 10-class Rice with Tungro virus, 11-class Brassica, and 3-class Potato), eliminating cross-crop chemical hazards ($0.0\%$ residual cross-routing). Browser WASM runs at 26--265\,ms p50 single-thread, inference-only. The server maintains PyTorch checkpoints via \texttt{YOLO()} for parity.
    \item \textbf{Deterministic knowledge resolver.} Structured lookups consult a compact fact base without calling the LLM. The current base holds 9 curated facts, so a 400-query held-out sweep saw no hits on this path; the path is extensible as the base grows and its cost is included in system overhead.
    \item \textbf{Hybrid grounded generation.} Unstructured queries use hybrid BM25~+ dense retrieval (BGE-M3/FAISS 8.34\,MB) over 2,946 institutional manuals and stream a fine-tuned Gemma-4 4-bit LoRA answer via SSE. BM25-only p50 is 26.8\,ms (p95~61.2\,ms) on 400 queries; dense retrieval needs an API key and falls back gracefully. End-to-end T3 with a stub LLM is reported as system overhead p50~33.6\,ms; live \texttt{llama-server} latency is not claimed as measured.
    \item \textbf{Relational verifier and escalation.} \texttt{HardenedDosageVerifier} checks dosage, formulation, and intervals against retrieved sources before rendering. Measured p50~4.82\,ms (p95~11.2\,ms). Unsupported claims lead to honest refusal or escalation, surfaced in the ``Why this advice?'' panel, rather than invention.
\end{enumerate}

\subsection{Dual-Audience Experience}
A toggle separates concerns without duplicating pages \citep{smartmatch2025}:

\begin{itemize}
    \item \textbf{Farmer mode:} conversational Bengali, large voice and photo affordances, and a structured Safe Action Card that foregrounds what to do, how much, and when, with evidence one tap away.
    \item \textbf{Expert and research mode:} confidence scores, retrieved snippets, 11-slot verification, full trace (safety $\rightarrow$ retrieval $\rightarrow$ generation $\rightarrow$ verifier), and replay controls that let an extension officer audit the same case the farmer sees.
\end{itemize}
