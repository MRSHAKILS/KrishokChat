# Final Decision

## Exact decision

Preserve the current architecture. Build no new agent topology. Add at most two research modules through existing ports:

1. **Module A:** structured Bengali agricultural claim/dosage relation verification plus calibrated risk-coverage abstention.
2. **Module B:** dialect-sensitive retrieval and safety-preserving normalization evaluation, with runtime normalization only if it passes native authenticity and safety gates.

Repair the vision treatment evidence defect as mandatory engineering work. Keep it outside the novelty claim.

## Four-week build list

- Evidence ledger for both authoritative PDFs and all local datasets/evals.
- Located and hashed dataset inventory, including nested candidates because root `dataset_release` is absent.
- Frozen structured-claim schema and expert annotation guide.
- Expert pilot and adjudicated evaluation subset.
- Lexical, LLM-judge, structured/NLI, and hybrid verifier baselines.
- Calibrated abstention analysis with risk-coverage curves.
- Paired standard Bangla/dialect/Banglish benchmark with raw and normalization conditions.
- BM25 retrieval and safety-router evaluation with paired statistics.
- Experiment manifests, split/seed controls, hashes, and error analysis.
- Vision defect specification and regression fixture; implement fix if ownership permits during execution.

## Eight-week build list

Everything in four weeks, plus:

- Integrate passing verifier and optional normalizer through domain/port/adapter/container seams.
- Repair vision evidence propagation and complete end-to-end regressions.
- Run blinded expert system evaluation.
- Report p50/p95 per-stage latency and failures on declared hardware.
- Run a bounded farmer-facing comprehension/trust/referral study only after ethics approval.
- Complete independent reproduction and release audit.

## Conditional list

- Activate hybrid retrieval only if dense artifacts, embedding configuration, corpus alignment, and benchmark reproduction pass Stage 0.
- Use a learned normalizer only if it beats Unicode/dictionary baselines and does not raise safety-intent flips.
- Use an LLM extractor only if its relation performance and latency justify it; otherwise use a structured deterministic/model hybrid.
- Include local Gemma comparisons only with model hash, serving config, and reproducible outputs.
- Include PDF numbers only after artifact reconciliation.
- Include a farmer study only with ethics approval, qualified supervision, safe stimuli, and recruitable participants.

## DO NOT BUILD

- New planner, critic, supervisor, debate, or multi-agent loops.
- Live web retrieval, web-search fallback, or parametric closed-book fallback for unsupported dosage.
- A new general Bengali agricultural QA dataset that duplicates existing team resources.
- A new object detector or bounding-box claim from classification artifacts.
- A chemical knowledge graph within this schedule.
- Fine-tuning as a prerequisite for the primary paper.
- Authentication, accounts, admin panels, external telemetry, queues, or microservices.
- UI polish framed as scientific contribution.
- Unverified benchmark endpoint numbers.

## Stop/go rules

- **Go A:** expert pilot supports a stable schema and at least one structured method improves the prespecified high-risk endpoint at acceptable coverage.
- **Go B:** native review validates paired data and normalization does not create an unacceptable safety regression under the frozen criterion.
- **Go integration:** each module passes independently and negative paths remain fail closed.
- **Stop runtime integration:** component evidence is inconclusive, latency is outside the declared envelope, or safety flips exceed the frozen limit.
- **Stop paper claim:** evidence cannot be traced to a hashed artifact and manifest.
