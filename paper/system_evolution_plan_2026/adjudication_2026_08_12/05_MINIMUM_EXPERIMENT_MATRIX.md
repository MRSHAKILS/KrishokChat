# Minimum Experiment Matrix

## Fixed Rules

- Split by source document, intent family, and transformation lineage. All forms of one intent remain in one split.
- Fit parsers, dictionaries, calibrators, and thresholds on train/development data only.
- Evaluate the frozen test split once. Corrections after freeze create a new dataset version and invalidate the prior confirmatory run.
- Use expert labels as gold. An LLM judge is a secondary baseline only.
- Record the manifest fields in `../06_EVALUATION_BENCHMARK_PLAN.md:100-103` for every run.
