1Background & Scientific Motivation

In agricultural advisory systems, crop ambiguity represents a severe safety hazard: recommending a rice herbicide or pesticide dosage to a farmer whose crop is potato, tomato, or chilli can burn crops and destroy livelihoods. In earlier versions of this research, 200 Bengali farmer queries were annotated by a single expert reviewer, which was disclosed as a limitation in the manuscript. This protocol establishes an independent second review to compute rigorous inter-annotator agreement (Cohen's κ) and establish a verified gold benchmark.

2How to Annotate: 4-Step Workflow

Step 1: Open Workbook
Open master_blind_sheet_200.xlsx (all 200 queries) or manageable modular batches in batches/batch_01...10.xlsx (20 queries each).
Step 2: Read Bengali Query
Read authentic farmer phrasing in Col D. Identify crop mentions, dialectal spellings, pests, symptoms, and fertilizer inquiries.
Step 3: Select Controlled Dropdowns
In Cols F, G, H, I, click the cell to reveal the in-cell dropdown menu. Choose from standardized options rather than free-typing.
Step 4: Automated Evaluation
Save the workbook. Run python scripts/evaluate_dual_review.py to compute agreement percentage, Cohen's κ, and autopsy discordances.

4Core Decision Rules (How to Avoid Random Annotations)

Rule 1: Explicit Crop Mention vs. Symptom Guesses (Crucial Safety Rule)
Do NOT guess or assume a crop just because a pest or symptom is mentioned!
• "মাজরা পোকা দমনে কী স্প্রে করব?" (Stem borer control): Even though stem borer attacks rice, it also attacks corn and sugarcane. Mark Is Crop Specified? = NO and Crop Taxonomy = none.
• "পাতার নিচে সাদা মাছি বসে পাতা হলুদ করে ফেলছে" (Whitefly yellowing): Whitefly attacks tomato, brinjal, chilli, and cotton with different chemical dosages. Mark NO / none.
Rule 2: Dialectal Names & Spelling Aliases
Bengali farmers use regional expressions that map to standard taxonomy:
• "আইলু" / "গোল আলু" → potato (আলু)  |  "আমন" / "বোরো" / "ইরি" / "স্বর্ণা" / "ব্রি ধান" → rice (ধান)
• "বিলাতি বেগুন" → tomato (টমেটো)  |  "কদু" → bottle_gourd (লাউ)  |  "ভেন্ডি" → okra (ঢেঁড়শ)

7Post-Annotation Agreement Evaluation (κ) & Automated Pipeline

Once Reviewer 2 completes all batches or the master sheet, the automated evaluation script is run. It compares Reviewer 2's labels against the sealed Reviewer 1 reference to calculate agreement statistics and isolate disagreements for consensus adjudication.

How to Run the Automated Agreement Script:
Open PowerShell / Terminal in the repository root and run:
cd "D:\KrishokChat Advisory System\paper\EACL Final\experiments\human_reviewer\scripts"
python evaluate_dual_review.py

Frequently Asked Questions (FAQ) for Annotators

Q1: What if the farmer mentions two crops, e.g., "ধান ও গম"?
A: Select the primary crop from the dropdown (e.g., rice) and add a note in Column J: "Dual crop: ধান ও গম".

Q2: What if the crop is not among the 36 named crops?
A: Select other_crop from the dropdown, write the exact Bengali name in Column E, and explain in Column J (e.g., "ড্রাগন ফল" or "পান সুপারী").

Q3: Should I correct spelling mistakes in the farmer's query?
A: No! Leave Column D completely untouched. The query reflects authentic farmer input with colloquial spellings.

Q4: Can I use Excel desktop or Google Sheets?
A: Both work! The files are standard .xlsx with standard openpyxl Data Validation dropdown lists compatible with Microsoft Excel, LibreOffice, and Google Sheets.

Pre-Submission Quality Checklist

• All 200 rows completed: No blanks in Column F (Crop EN), Column G (Specified?), or Column H (Intent).
• Valid dropdown tokens used: No typos or unauthorized category names entered.
• Double-blind preserved: Review performed without referencing model outputs or Reviewer 1 labels.
• Saved properly: Files saved in batches/ or master_blind_sheet_200.xlsx.
