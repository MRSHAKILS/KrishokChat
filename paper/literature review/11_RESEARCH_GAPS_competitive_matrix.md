## Gap 1: Calibrated Abstention Unmeasured in Bengali Agricultural QA

**Matrix Evidence:** ConfRAG row — Convergence column: hallucination 20–40% → <5% exists only after ConfQA fine-tuning, English atomic facts only (LITERATURE_REVIEW.md §1.1). Self-RAG row — Core Architecture: trained reflection tokens, no abstain terminal (§1.2). Farmer.Chat row — Convergence: action-confidence 86% vs 48% when information complete vs incomplete, n=450 Kenya (§3.1). Adaptive-RAG and CRAG rows: no abstention mechanism of any kind (§1.4, §6.5).

**Formal Object:** Per-domain expected calibration error (ECE). Raw log-probabilities are miscalibrated until fitted to a domain set: ECE 0.275→0.062 (TriviaQA), 0.643→0.009 (NQ), 0.711→0.031 (MS MARCO) after calibration (arXiv:2606.29959, §1.9). No ECE curve or calibrated abstention protocol exists for Bengali agricultural QA; the review records this as its own open question (§9.1). The competitor denominators are absent: ConfRAG calibrates on English atomic facts (§1.1); Farmer.Chat's 86%/48% cliff is a field measurement of abstention cost without any published gate (§3.1).

**Failure Characterization:** Farmers over-trust uncalibrated answers: deliberately wrong AI advice reduces willingness to withhold judgment by 41 percentage points (§4.2), and longer explanations raise user confidence without raising accuracy (§5.1). Measurable consequences: refusal precision on a ~100-query held-out Bangla calibration set (§7.3) and the confidence–correctness gap (ECE) that none of the five competitor rows reports.

**Seed Lever:** API-compatible abstention proxy with in-file feasibility evidence: consistency sampling + Jaccard similarity (F1 0.593 at 1.46 searches vs 0.552 at 4.60 always-retrieve, §1.3) feeding a logistic calibrator (§7.3) and the 4-way gate converting the binary trigger into FULLY_GROUNDED / PARTIALLY_GROUNDED / GENERAL_GUIDANCE / REFER_EXPERT actions (§7.1).

**Peer-Review Attack Vector & Rebuttal Pre-emption:** Dismissal: "train an 'unsure' emitter like ConfRAG" — fails on constraint: ConfQA (§1.1) and Self-RAG reflection tokens (§1.2) require generator fine-tuning, which the locked black-box API excludes (constraint recorded in §1.2, §6.6, AGENTS.md §3). Dismissal: "borrow Farmer.Chat's completeness handling" — fails on evidence: 60 Decibels measured the 38-point cliff (§3.1) and published no gate, no calibration curve, no threshold. The dismissal requires producing the absent object — a Bengali agricultural calibration set with ECE — which is the gap itself.

## Gap 2: Pre-Retrieval Safety Routing Absent from Every RAG Gating Architecture

**Matrix Evidence:** Self-RAG row — Theoretical Vulnerabilities: ISSUP gates support, not safety. CRAG row — Core Architecture: relevance evaluator (Correct/Incorrect/Ambiguous) with no safety class (§6.5). Adaptive-RAG row — complexity-only routing, 3 levels (§1.4). ConfRAG row — binary unsure trigger (§1.1). Farmer.Chat row — no published decision classes (§3.1). None of the five places any decision point with terminal categories upstream of retrieval.

**Formal Object:** Taxonomy containment. Let $T_{seed} = \{safe\_agri,\ banned\_or\_restricted\_chemical,\ self\_harm\_or\_poisoning\_risk,\ off\_topic,\ prompt\_injection,\ low\_confidence\}$ (AGENTS.md §4). For each competitor $i$, the published decision vocabulary satisfies $T_i \cap T_{seed} \subseteq \{\emptyset\}$: Self-RAG = {Retrieve, ISREL, ISSUP, ISUSE} (§1.2); Adaptive-RAG = {null, single, multi} (§1.4); ConfRAG = {unsure, confident} (§1.1); CRAG = {Correct, Incorrect, Ambiguous} (§6.5); Farmer.Chat = no published classes. The terminal classes (banned chemical, poisoning, injection) have zero intersection with every $T_i$. Verifiable by class-name inspection of each cited paper.

**Failure Characterization:** A banned-or-restricted-chemical query passes the first stage of all five pipelines unchanged. Retrieval then surfaces dosage-bearing passages and the generator emits ungrounded dosage advice — the output §7.4 forbids: "if the specific number matters for safety → refuse and redirect." Measurable: ungrounded-dosage emission rate on the banned-chemical class. None of the five rows can log the decision because none has the category (audit schema §7.8).

**Seed Lever:** Pre-retrieval Safety/Router: regex precheck + JSON classification into 6 classes, with 4 terminal categories (banned chemical, poisoning/self-harm → canned 16123/999 redirect and stop). The only pipeline among the six with a decision boundary before any retrieved context enters the generator (AGENTS.md §4).

**Peer-Review Attack Vector & Rebuttal Pre-emption:** Dismissal: "add a safety prompt to the generator" — fails on placement: a generator-side instruction executes after retrieval, which is already too late for a poisoned-context attack (Gap 3's CRAG evidence: Incorrect retrieval → fallback emission), and after generation no terminal exists. Dismissal: "reuse Llama Guard or XSafety classes" — fails on taxonomy: the published class sets (14 MLCommons hazards; 10-language XSafety) contain no banned-agrochemical or poisoning category, and no competitor row publishes evaluation data for such a class. The missing object is a benchmark with the class, not a prompt.

## Gap 3: Corrective Action Spaces Lack Safety-Monotone Refusal Operators

**Matrix Evidence:** CRAG row — Core Architecture + Theoretical Vulnerabilities: Incorrect → discard + web-search fallback; Ambiguous → combine internal + external knowledge (§6.5). Self-RAG row — reflection tokens refine or reject on support, never refuse terminally (§1.2). ConfRAG row — halts RAG, continues closed-book generation (§1.1). Adaptive-RAG row — no corrective stage (§1.4).

**Formal Object:** Safety-monotonicity of corrective action grammars. §7.4 defines a risk ordering over answer content: general guidance < named active ingredient < exact dosage/brand/frequency/safety interval, where the final tier is unsafe to emit without KB grounding. CRAG's action grammar $A_{CRAG} = \{refine,\ web\_search\_fallback,\ combine\}$ maps a low-information state (Incorrect retrieval) to a higher-risk emission channel (parametric web generation) for unsafe-tier queries. Define safety-monotone: an action grammar $A$ satisfies monotonicity if every action either preserves or lowers emission risk for every tier. $A_{CRAG}$ and $A_{ConfRAG}$ (halt, then generate closed-book) violate it. Seed's gate grammar $A_{seed} = \{ground,\ partial\_flag,\ general\_flag,\ refuse\_16123\}$ (§7.1, REFER_EXPERT rule) satisfies it.

**Failure Characterization:** High-consequence (dosage/timing) query with Incorrect or Ambiguous retrieval → CRAG falls back to web search → ungrounded dosage content reaches the farmer. Automation-bias harm is documented in-file: incorrect AI recommendations worsen judgment across experience levels (§4.4); wrong-and-confident output is the launch-blocking combination (§4.2). Measurable: ungrounded-claim rate within the critical tier under each grammar. Audit closure (§7.8) is impossible for fallback channels because the fallback source is parametric and unlogged.

**Seed Lever:** Post-generation Verifier with dosage-token flagging plus the REFER_EXPERT terminal ("empty KB + treatment intent → REFER_EXPERT always", calibration rules; §7.4). The only action space among the six with a monotone refusal operator positioned after generation.

**Peer-Review Attack Vector & Rebuttal Pre-emption:** Dismissal: "web-search fallback is standard practice (Bing Copilot, Perplexity)" — fails on measured failure: retrieval-first systems with parametric fallback carry a 37% error rate with two named failure types, misattribution and fabrication (CJR audit, §2.1); parametric fallback is failure mode #1 of grounded-generation architectures (§6.8). Dismissal: "refusal harms usefulness" — the tradeoff at stake is ungrounded emission, not refusal; Farmer.Chat's field result ties incomplete handling to a 38-point confidence loss (§3.1), which the REFER terminal addresses by redirecting to 16123 instead of emitting.
