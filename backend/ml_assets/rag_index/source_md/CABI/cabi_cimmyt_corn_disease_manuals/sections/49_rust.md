# Rust

*Puccinia purpurea*

Worldwide

![img-184.jpeg](sections/images/49_p163_img-184.jpeg)

Photo: S Nelson, Flickr

- Purple-red spots on both leaf surfaces, parallel to veins, they mature to 'bumps', which break into reddish powdery masses (pustules).
- On the head stalk long brownish streaks develop.
- Later in the season black spots develop on leaves; this is the same problem but in a different phase.
