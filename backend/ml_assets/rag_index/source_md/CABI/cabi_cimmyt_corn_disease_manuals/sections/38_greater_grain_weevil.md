# Greater grain weevil

*Sitophilus zeamais*

Worldwide

![img-173.jpeg](sections/images/38_p152_img-173.jpeg)

Photo: Gary Alpert, Harvard University, Bugwood.org

- 3 mm long but very similar to the lesser grain weevil.
- Four orange spots on wing cases but not as clear as in the lesser grain weevil.
- Pest of stored grain, larvae are found inside the stored seeds.
