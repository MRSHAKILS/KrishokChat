# Maize mosaic virus

MMV symptoms shown on Maize

Worldwide

![img-230.jpeg](sections/images/95_p209_img-230.jpeg)

Photo: CIMMYT

- Transmitted by hopper *Peregrinus maidis*.
- Discontinuous chlorotic streaks between fine veins stunting and yield loss.
- Severe if infection of young seedlings, takes place grain set reduces.
