# Swede midge
*Contarinia nasturtii*

![img-61.jpeg](sections/images/30_p48_img-61.jpeg)

Photo: Susan Ellis, USDA APHIS PPQ, Bugwood.org

- A tiny, light brown fly that looks a bit like a mosquito.
- Several generations a year, which means adults can be seen in any month.
- The pupa is found in the soil.
