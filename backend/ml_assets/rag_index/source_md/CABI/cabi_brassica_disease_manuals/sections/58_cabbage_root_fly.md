# Cabbage root fly

*Delia radicum*

![img-90.jpeg](sections/images/58_p76_img-90.jpeg)

Photos: Clemson University – USDA Cooperative Extension Slide Series, Bugwood.org
Mary Ann Hansen, Virginia Polytechnic Institute and State University, Bugwood.org

- Stunted plants that wilt easily.
- Root system very poorly developed and plants easily lifted from the soil.
