## GROUP SESSION PLANNING

Day -02

Time- 10.00 am

Duration – 30 minutes

Target group : Women famers of Household based pond aquaculture and homestead gardening
Title of session : Revision of previous day's session
Aim : Participants will narrate and discuss previous day's sessions, express their opinions so that previous day's discussion are recalled and an gaps in understanding resolved.
Objective : At the end of this session, the participants -
• Will be able to come to a common understanding on previous day's sessions through discussion

|  Discussion topic | Training approach | Duration  |
| --- | --- | --- |
|  Introduction |  | 5 minutes  |
|  1. Welcome/reception: welcoming the participants and asking about participants welfare 2. Discussion about previous session 3. Linking previous session's topic to current session 4. Explanation of aim and objectives of current session | Q&A and discussion |   |
|  Topic |  | 22 minutes  |
|  • One participant will review previous day's session through discussion • Everyone's opinion taken on previous day's session | Q&A, Lecture and Flipcharts |   |
|  Summary |  | 3 minutes  |
|  1. Summary discussion of main topic 2. Assessment of session objectives | Q&A |   |
