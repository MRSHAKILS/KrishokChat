# BARI Sarisha-18 Profile & Oil Quality (Canola)

## স্বল্পমেয়াদী ও ক্যানোলা জাতীয় সরিষার জাত পরিচিতি ও উৎপাদন কলাকৌশল

### বারি সরিষা-১৮ (ক্যানোলা জাত):

#### তেলের গুণগত মান

|  ইরোসিক এসিড | : ১.০৬% (সাধারণ সরিষায় : ৪০-৪৫%)  |
| --- | --- |
|  লিনোলিক এসিড (ওমেগা-৬) | : ২৪% (সাধারণ সরিষায় : ১৪-১৫%)  |
|  লিনোলেনিক এসিড (ওমেগা-৩) | : ৯% (সাধারণ সরিষায় : ৭-৮%)  |
|  ওলিক এসিড (ওমেগা-৯) | : ৫৮% (সাধারণ সরিষায় : ১৭-২০%)  |
|  গ্লুকোসিনোলেট (মাইক্রোমোল/গ্রাম): | ১৪ মাইক্রোমোল/গ্রাম (সাধারণ সরিষায়: ১৯-২৪%)  |

#### জাতের বৈশিষ্ট্য

|  জীবনকাল | : ৯৫-১০০ দিন  |
| --- | --- |
|  শস্যবিন্যাস | : আমন ধান-সরিষা-পাট/ডাল জাতীয় ফসল/অন্যান্য ফসল শস্য বিন্যাসে চাষের উপযোগী।  |
|  উচ্চতা | : ৯০-১২৫ সেমি যা মধ্যম খাটো।  |
|  পাতা | : গাঢ় সবুজ রঙের, মসৃণ ও লোমহীন। পাতা বোটাবিহীন এবং পুষ্পপত্রের গোড়ার অংশ কাণ্ডকে অর্ধেক ঘিরে রাখে।  |
|  ফুল | : মঞ্জুরীদণ্ডে সদ্য প্রস্ফুটিত ফুল কুঁড়ির নিচে অবস্থান করে। ফুলের রং হলুদ। গাছে দীর্ঘ দিন যাবৎ ধরতে থাকে।  |
|  শুটি | : প্রতি গাছে শুটির সংখ্যা ৮০-১৩০টি। এর শুটি বেশ লম্বা ও দু'কক্ষ বিশিষ্ট। প্রত্যেক শুটিতে বীজের সংখ্যা ২৮-৩০টি।  |
|  বীজ | : বীজের রং পিঙ্গল কালো। ১০০০ বীজের ওজন ৩.৫-৪.০ গ্রাম।  |
|  বীজে তেলের পরিমাণ | : ৪০-৪২%।  |
|  বপনের উপযুক্ত সময় | : অক্টোবরের শেষ সপ্তাহ থেকে নভেম্বরের মাঝামাঝি।  |
|  বীজের ফলন | : প্রতি হেক্টরে ২০০০-২৫০০ কেজি। এ জাতটি বারি সরিষা-১৪ এর চেয়ে ৩০-৬০% ভাগ বেশি ফলন দেয়।  |
