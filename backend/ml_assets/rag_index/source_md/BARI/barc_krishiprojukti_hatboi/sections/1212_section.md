## স্বল্প মূল্যের ড্রিপ সেচ পদ্ধতি

বাড়ির আশেপাশের ফল বা সবজি বাগানে ছোটখাটো জমিতে সেচ প্রদানের জন্য স্বল্প মূল্যে এ ড্রিপ সেচ পদ্ধতি বেশ কার্যকর। সেচ পদ্ধতি প্রান্তিক চাষীদের জন্য অত্যন্ত উপযোগী।
