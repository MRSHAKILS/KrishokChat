# **ইক্ষু + আলু + গিমাকলমী আন্তঃফসল**

|  ভূমি শ্রেণি ও কৃষি পরিবেশ অঞ্চল (কুপ) | আন্তঃফসল | কাজিকত ফলন (কেজি/শতাংশ) | সার সুপারিশ (গ্রাম/শতাংশ) |   |   |   |   |   |   | জৈব সার (কেজি/ শতাংশ)  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
|   |   |   |  ইউরিয়া | টিএসপি | এমওপি | জিপ সাম | *ম্যাগ. সাল. | জিংক সাল. | বোরিক এসিড  |   |
|  উঁচু ও মাঝারি উঁচু জমি: কুপ: ১, ১১, ২৫ | ইক্ষু (জোড় সারি) + আলু + গিমাকলমী | ৪০৫ ৪০ ৪০ | ১৩২০ ৬১৬ ২৪৬ | ৪৫৫ ১৩৭ ২৫৫ | ৮১০ ৪৮৬ ২৪৩ | ৬৭৫ - ৪৫ | ৮৫২ - - | - - - | - - - | - - -  |

* ম্যাগনেসিয়াম সালফেট কৃষি পরিবেশ অঞ্চল ১ ও ২৫ এর জন্য

**বপনের সময় :** ইক্ষু ও আলু:কার্তিক; গিমাকলমী: ফাল্গুন-বৈশাখ

**বপন পদ্ধতি :** জোড় সারি আখের (৫৬ ইঞ্চি - ২৪ ইঞ্চি x ১৮ ইঞ্চি) মধ্যে তিন সারি আলু ও গিমাকলমী (১২ ইঞ্চি দূরত্বের সারিতে) লাগাতে হবে।

**সার প্রয়োগ পদ্ধতি :** ইক্ষুর অর্ধেক এমওপি এবং সমুদয় টিএসপি, জিপসাম ও ম্যাগনেসিয়াম সালফেট শেষ চাষের সময় ছিটিয়ে প্রয়োগ করতে হবে। ইউরিয়া সার সমান তিন ভাগে ইক্ষু রোপণের ২০ দিন পর, ৪-৬টি কুশি স্তরে ও ভ্যালি তৈরির সময় আখের সারিতে প্রয়োগ করতে হবে। বাকি অর্ধেক এমওপি ৪-৬টি কুশি স্তরে ইউরিয়া প্রয়োগের সময় প্রয়োগ করতে হবে। আলুর অর্ধেক ইউরিয়া ও এমওপি এবং অন্যান্য সমুদয় সার শেষ চাষের আগে ছিটিয়ে প্রয়োগ করতে হবে। বাকি অর্ধেক ইউরিয়া ও এমওপি ৩০-৩৫ দিন পর আলুর ভ্যালি তৈরির সময় সারিতে পার্শ্ব প্রয়োগ করতে হবে। গিমাকলমীর সমুদয় সার শেষ চাষের সময় ছিটিয়ে প্রয়োগ করতে হবে।
