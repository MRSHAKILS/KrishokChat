# সার হিসাবের কিছু প্রয়োজনীয় তথ্য

|  ইউরিয়া (কেজি) = কেজি নাইট্রোজেন × ২.১৭ | ১ কেজি = ২.২৪ পাউন্ড  |
| --- | --- |
|  ডিএপি (কেজি) = কেজি নাইট্রোজেন × ৫.৫৬ অথবা কেজি ফসফরাস × ৫.০ | ১ পাউন্ড = ০.৪৫৪ কেজি  |
|  টিএসপি (কেজি) = কেজি ফসফরাস × ৫.০ | ১ পাউন্ড/একর = ১.১২ কেজি/হেক্টর  |
|  এমওপি (কেজি) = কেজি পটাশিয়াম × ২.০ | ১ হেক্টর = ২.৪৭ একর ১ কেজি/হেক্টর = ০.৮৯ পাউন্ড/একর  |
|  জিপসাম (কেজি) = কেজি সালফার × ৫.৫৬ | ১ একর = ০.৪০ হেক্টর  |
|  জিংক সালফেট, হেপাটাইট্রেট (কেজি) = কেজি জিংক × ৪.৩৫ | ১ একর = ১০০ শতাংশ  |
|  বোরিক এসিড (কেজি) = কেজি বোরন × ৫.৮৮ | ১ শতাংশ = ৪০.৪৮ বর্গমিটার  |
|  ১ হেক্টর = ১০,০০০ বর্গ মিটার | ১ ইঞ্চি = ২.৫৪ সেন্টিমিটার  |
|  ১ বর্গ মিটার = ১/১০,০০০ হেক্টর | ১ মিটার = ৩৯.৩৭ ইঞ্চি  |
