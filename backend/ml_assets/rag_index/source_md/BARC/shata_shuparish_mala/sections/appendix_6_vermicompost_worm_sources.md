# **তামিকস্পোষ্ট তৈরির জন্য প্রয়োজনীয় কেঁচোর প্রাপ্তিস্থান**

# **পরিশিষ্ট-৬**

1. মৃত্তিকা বিজ্ঞান বিভাগ, বাংলাদেশ কৃষি গবেষণা ইনস্টিটিউট, গাজীপুর
2. এগ্রো বিয়ার্তা সোসাইটি, গ্রাম-বিয়ার্তা, পোঃ আহাম্মদ বাড়ী, থানা-ত্রিশাল, জেলা-ময়মনসিংহ
3. কৃষি কল্যাণ বহুমুখী সমবায় সমিতি, ওলিপুর, উল্লাপাড়া, পাবনা
4. সুহৃদ (SUHRID), এপটিমেন্ট নং # এ-১, বাড়ী নং # এ-৫৭, রোড নং #১, নিকেতন, ঢাকা
5. বাসা (BASA), বাড়ী নং # ২৪৭, রোড নং # ১৮, নিউ ডি ও এইচ এস, মহাখালী, ঢাকা
6. জি কে এস এস জৈব সার কারখানা, আমতলী, সারিয়াকান্দি, বগুড়া
7. সেবা সংঘ কৃষি ক্লাব, মহেশ্বরচান্দা, কালিগঞ্জ, বিনাইদহ
8. কেঁচো মানিক, বীরগঞ্জ, দিনাজপুর
9. মেসার্স সিএমইএস, সে ও সে তামিকস্পোষ্ট, সুরজ, গোসাইর, সদর, টাঙ্গাইল
10. মিসেস রেবেকা সুলতানা, গ্রামীণ কৃষক সহায়ক সংস্থা (জিকেএসএস), যাসনাপাড়া, গাবতলী বগুড়া
11. মিসেস মর্জিনা বেগম, স্বপ্ন তামিকস্পোষ্ট, গ্রাম: মহাশ্বেরচান্দা, উপজেলা: কালীগঞ্জ, জেলা: বিনাইদহ
12. মিসেস সেলিনা জাহান, সেলিনা অর্গানিক ফার্ম, শিবগঞ্জ, নরসিংদী
13. রহমান এগ্রো ফার্মিং, ফকিরপাড়া, দিনাজপুর
14. কৃষিবিদ আঃ খালেক, প্রগতি তামিকস্পোষ্ট, বীরগঞ্জ, দিনাজপুর
15. মোসাঃ মোমেনা, গ্রাম-পাজুলিয়া, পোঃ-চত্বর, গাজীপুর সিটি কর্পোরেশন
16. রাম নিবাস আগরওয়ালা, বনওয়ারী মোড়, ডোমার, নীলফামারী
17. মোসাঃ জালাতুল ফেরদৌস, টি.আর. এগ্রোঃ কোঃ লিঃ, গ্রাম+ পোঃ-আমবুপি, উপজেলা-মেহেরপুর সদর, জেলা-মেহেরপুর
18. রায়হান হোসেন রিফ্টি, অহনা এগ্রোঃ ফার্ম, গ্রাম-চৌপুকুরিয়া, পোঃ-সাতোর, উপজেলা-বীরগঞ্জ, জেলা-দিনাজপুর
19. মোঃ মনোয়ার হোসেন, গ্রাম-ইছাখালী, পোঃ-নতুন বাজার, চাটমোহর, উপজেলা-চাটমোহর, জেলা-পাবনা
20. মোঃ মহির উদ্দিন, রাখাল এগ্রোঃ প্রাঃ লিঃ, গ্রাম-হোগলবারীয়া, পোঃ-মোহম্মদপুর, উপজেলা-গাংনী, জেলা-মেহেরপুর
21. খন্দকার শাহেদ আলী, উজিরপুর মাল্টিপারপাস কোঅপারেটিভ লিঃ, গ্রাম-উজিরপুর, পোঃ-বকুলতলা, উপজেলা-নড়াইল সদর, জেলা-নড়াইল
22. মোসাঃ তানজিমা খাতুন, সিয়াম তামিকস্পোষ্ট, গ্রাম-সরসপুর, পোঃ-শাহাবাদ, উপজেলা-নড়াইল সদর, জেলা-নড়াইল
23. মোঃ সাদেকুল ইসলাম, গ্রাম-মীরপুর, পোঃ-বড় গাছীর হাট, উপজেলা-ভোলাহাট, জেলা-চাপাইনবাবগঞ্জ।
24. মোঃ ইসহাক আলী, এনভারমেন্টাল রিসোর্সেস এডভান্সমেন্ট সার্ভিস, গ্রাম-চাকারোড, পোঃ-সান্তাহার উপজেলা-আদম দিঘী, জেলা-বগুড়া
25. মোঃ মতিউর রহমান, গ্রাম-বড় চং খোলা, পোঃ-উত্তর পদুয়া, উপজেলা-রাঙ্গুনিয়া, জেলা-চট্টগ্রাম
26. মোঃ আবুল কালাম আজাদ, বাংলাদেশ এক্সটেনশন এডুকেশন সার্ভিস, গ্রাম-মুনিয়া গাড়ী, পোঃ-পলাশবাড়ী, উপজেলা-পলাশবাড়ী, জেলা-গাইবান্ধা
27. মোঃ শাহেব জামাল, গ্রাম-ঐরামপুর, পোঃ-ধাপের হাট, উপজেলা-পীরগঞ্জ, জেলা-রংপুর
28. মোঃ বদরুল হায়দার বেপারি, গ্রাম-চৌঠাই মহল, পোঃ-নাজিরপুর, উপজেলা-নাজিরপুর, জেলা-পিরোজপুর
29. মোঃ মজিবর রহমান, গ্রাম-গুপ্তদিয়া, পোঃ-কাকরাইদ, উপজেলা-মধুপুর, জেলা-টাঙ্গাইল
30. মোঃ এসতাক রহমান, গ্রাম-রাজাপুর, পোঃ-রাউলিয়াবাদ, উপজেলা-মাধবপুর, জেলা-হবিগঞ্জ
