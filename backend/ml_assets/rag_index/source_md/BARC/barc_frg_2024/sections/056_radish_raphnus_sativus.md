## YARDLONG BEAN (*Vigna unguiculata*)

(Var. BARI Barboti-1, BARI Barboti-2, Kagor Natoki)

Yield Goal: 15.0 ±1.5 t/ha

|  Soil Analysis Interpretation | Nutrient Recommendation (kg/ha) |   |   |   |   |   | OF (t/ha)  |
| --- | --- | --- | --- | --- | --- | --- | --- |
|   |  N | P | K | S | Zn | B  |   |
|  Optimum | 0-12 | 0-7 | 0-14 | 0-5 | – | – | 5  |
|  Medium | 13-24 | 8-14 | 15-28 | 6-10 | 0.0–1 | 0.0–0.7  |   |
|  Low | 25-36 | 15-21 | 29-42 | 11-15 | 0.7–2 | 0.7–1.4  |   |
|  Very low | 37-48 | 22-28 | 43-56 | 16-20 | 1.3- 3.0 | 1.3–2.1  |   |

### Method of application:

1. All fertilizers except N should be applied as basal during final land preparation.
2. Nitrogen should be applied in two equal splits during 2$^{nd}$ and 4$^{th}$ weeks of germination.
3. *Rhizobium* inoculum (at the rate of 50 g/kg seed) should be used if available and in that case N fertilizer should not be used.

## FRENCH BEAN (*Phaseolus vulgaris*)

(Var. BARI Jharsheem-1, BARI Jharsheem-2, BARI Jharsheem-3)

Yield Goal: 15.0 ± 1.5 t/ha

|  Soil Analysis Interpretation | Nutrient Recommendation (kg/ha) |   |   |   |   |   | OF (t/ha)  |
| --- | --- | --- | --- | --- | --- | --- | --- |
|   |  N | P | K | S | Zn | B  |   |
|  Optimum | 0-19 | 0-10 | 0-20 | 0-4 | – | – | 3  |
|  Medium | 20-38 | 11-20 | 21-40 | 5-8 | 0.0–1.0 | 0.0–0.7  |   |
|  Low | 39-57 | 21-30 | 41-60 | 9-12 | 1.1–2.0 | 0.8–1.4  |   |
|  Very low | 58-76 | 31-40 | 61-80 | 13-16 | 2.1–3.0 | 1.5–2.1  |   |

### Method of application:

1. All of OF, P, K, S, Zn and B; and one-third of N should be applied as basal during final land preparation.
2. Remaining N should be side dressed at 20 and 35 DAS under moist soil condition and mixed thoroughly with the soil.
