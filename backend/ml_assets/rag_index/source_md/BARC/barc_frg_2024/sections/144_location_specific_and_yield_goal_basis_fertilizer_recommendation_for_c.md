# Location specific and Yield goal basis fertilizer recommendation for crops

*Based on soil test values*

*Example:* Crop Wheat (High Yield Goal; HYG) = 4.5 ± 0.45 t/ha

**Location:** Village ...

Upazila ...

District ...

Fertilizer requirement of crops based on given soil test values can be computed by three methods. The methods are outlined below.

# Method 1. Computation of fertilizer requirement for crops by using formula -1

$$
\mathrm{NR} = \mathrm{MRN} - \frac{\mathrm{MRN}}{\mathrm{Opt/Med}} \times \mathrm{STV}
$$

*Where,*

**NR** = Nutrient requirement based on Soil Test Value (STV)

**MRN** = Maximum recommended nutrient dose for target yield

**Opt** = Highest STV Value of class OPTIMUM for Macronutrients

**Med** = Highest STV Value of class MEDIUM for Mg* and Micronutrients

**Step-I** : Use the maximum recommended nutrient (**MRN**) dose for respective crop as depicted in Chapter 7.

Example: Wheat (yield 4.5 t/ha)

|  Name of nutrient | Maximum nutrient dose (kg/ha)  |
| --- | --- |
|  N | 160  |
|  P | 40  |
|  K | 120  |
|  Mg | 12  |
|  S | 20  |
|  Zn | 3.9  |
|  B | 3  |

**Step-II:** Use the highest STV of class OPTIMUM for Macronutrients and highest STV of class MEDIUM for Mg and micronutrients (**Appendix 8**)

*Mg use for wheat, potato, sweet potato, mustard and sunflower.

Example: Wheat (yield 4.5 t/ha)

|  Highest value of class Optimum |   |   |   | Highest value of class Medium  |   |   |
| --- | --- | --- | --- | --- | --- | --- |
|  N % | P mg/kg | K meq/100g | S mg/kg | Zn μg/g | B μg/g | Mg meq/100g  |

# Calculation of fertilizer dose:

$$\mathrm{N} (\mathrm{kg} / \mathrm{ha}) = 160 - \frac{160}{0.36} \times 0.1 = 116$$

$$\text{Urea (kg/ha)} = 116 \times \frac{100}{46} = 252$$

$$\mathrm{P} (\mathrm{kg} / \mathrm{ha}) = 40 - \frac{40}{36} \times 20 = 17.8$$

$$\text{TSP/DAP (kg/ha)} = 17.8 \times \frac{100}{20} = 89$$

$$\mathrm{K} (\mathrm{kg} / \mathrm{ha}) = 120 - \frac{120}{0.36} \times 0.15 = 70$$

$$\text{MOP (kg/ha)} = 70 \times \frac{100}{50} = 140$$

$$\mathrm{Mg} (\mathrm{kg} / \mathrm{ha}) = 12 - \frac{12}{1.20} \times 0.80 = 4.0$$

$$\text{Magnesium sulphate (kg/ha)} = 4.0 \times \frac{100}{9.5} = 42.1$$

$$\mathrm{S} (\mathrm{kg} / \mathrm{ha}) = 20 - \frac{20}{43.2} \times 15 = 13.1$$

$$\text{Gypsum (kg/ha)} = 13.1 \times \frac{100}{18} = 73$$

$$\mathrm{Zn} (\mathrm{kg} / \mathrm{ha}) = 3.9 - \frac{3.9}{1.62} \times 1.2 = 1.01$$

$$\text{Zinc sulphate (hepta-hydrate) (kg/ha)} = 1.01 \times \frac{100}{21} = 4.86$$

$$\mathrm{B} (\mathrm{kg} / \mathrm{ha}) = 3 - \frac{3}{0.609} \times 0.21 = 1.97$$

$$\text{Boric acid (kg/ha)} = 1.97 \times \frac{100}{17} = 11.6$$

Hence, the final recommendation would be

|  Name of nutrient | Nutrient dose (kg/ha) | Name of fertilizer | Fertilizer (kg/ha) | Fertilizer / Nutrient Ratio  |
| --- | --- | --- | --- | --- |
|  N | 116 | Urea | 252 | 2.17  |
|  P | 17.8 | TSP or DAP | 89 | 5.00  |
|  K | 70.0 | MOP | 140 | 2.00  |
|  Mg | 4.00 | Magnesium sulphate | 42.1 | 10.52  |
|  S | 13.1 | Gypsum | 73 | 5.55  |
|  Zn | 1.02 | Zinc sulphate, hepta-hydrate | 4.86 | 4.75  |
|  B | 1.97 | Boric acid | 11.6 | 5.88  |

Note: When magnesium sulphate and zinc sulphate (hepta- hydrate) are used, sulphur is also supplied (10.5% S in $\mathrm{ZnSO_4.7H_2O}$ and 12.5 % Mg in $\mathrm{MgSO_4.H_2O}$). Thus, if 4.86 kg of zinc sulphate (hepta-hydrate) and 42.1 kg Magnesium sulphate are used

$$
\frac{42.1 \times 12.5}{100} = 5.26 \text{ kg of S will be supplied from magnesium sulphate}
$$

$$
\frac{4.86 \times 10.5}{100} = 0.51 \text{ kg of S will be supplied from zinc sulphate}
$$

Thus, the S requirement can be reduced to $13.1 - (5.26 + 0.51) = 7.33 \text{ kg S/ha}$. The new calculation for sulphur from gypsum would then be -

$$
\frac{100 \times 7.03}{18} = 39.05 \text{ kg gypsum per hectare}
$$

Method 2. Computation of fertilizer requirement for crops by using formula -2

$$
\mathrm{NR} = \mathrm{U_f} - \mathrm{X} \frac{\mathrm{C_i}}{\mathrm{C_s}} \mathrm{X} (\mathrm{S_t} - \mathrm{L_s})
$$

Where,

$\mathrm{NR} =$ Nutrient requirement based on Soil Test Value (STV)

$\mathrm{U_f} =$ Upper limit of the recommended nutrient for the respective STVI class

$\mathrm{C_i} =$ Units of class intervals used for fertilizer nutrient recommendation

$\mathrm{C_s} =$ Units of class intervals used for STVI class

$\mathrm{S_t} =$ Soil test value

$\mathrm{L_s} =$ Lower limit of the soil test value within STVI class

Example: Given Soil Test Value (STV) and its interpretation for upland crops
