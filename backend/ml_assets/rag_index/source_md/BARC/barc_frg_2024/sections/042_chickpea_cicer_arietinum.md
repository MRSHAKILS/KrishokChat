# Method of application:

a) All fertilizers should be applied as basal during final land preparation.
b) Rhizobium inoculum (at the rate of \(50\mathrm{g / kg}\) seed or \(1.5\mathrm{kg / ha}\)) should be used if available and in that case N fertilizer should not be used.
