## মাছ চাষে ব্যবহৃত কিছু প্রয়োজনীয় মাপের একক

| --- | --- | --- |
|  ১ ইঞ্চি | = | ২.৫৪ সেন্টি মিটার (সে.মি)  |
|  ১ মিটার | = | ৩.২৮১ ফুট  |
|  ১ শতাংশ | = | ৪৩৫.৬ বর্গফুট = ৪০ বর্গমিটার (প্রায়)  |
|   | = | ১৪ হাত X ১৪ হাত (প্রায়)  |

|  ১ বিঘা | = | ৩৩ শতাংশ = ১,৩২০ বর্গমিটার (প্রায়)  |
|  ১ একর | = | ১০০ শতাংশ = ৪,০০০ বর্গমিটার (প্রায়)  |
|  ১ হেক্টর | = | ২৪৭ শতাংশ = ২.৫ একর (প্রায়) = ১০,০০০ বর্গমিটার  |

|  ১ গ্রাম | = | ১,০০০ মিলি গ্রাম (মি.গ্রা)  |

|  ১ পি পি টি (পার্টস পার থাউসেন্ড) | = | প্রতি লিটারে ১ গ্রাম বা = প্রতি ঘন মিটারে ১০০০ গ্রাম (এক হাজার ভাগের এক ভাগ)  |
